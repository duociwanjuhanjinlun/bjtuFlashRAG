# bjtuFlashRAG

2025竞赛：基于FlashRAG的智能DeepSearch系统设计

赛题要求如下：

### 赛题介绍

#### 赛题名称

**基于FlashRAG的智能DeepSearch系统设计**

#### 赛题背景

FlashRAG是由中国人民大学研发的新一代RAG工具包，集成了先进的检索与生成算法，提供了丰富的RAG数据集和文档集合，为DeepSearch系统的开发提供了强有力的技术支撑。
DeepSearch系统的核心挑战在于如何通过多层次、多策略的检索与生成流程，实现对复杂问题的深度解析与回答。具体难点包括：

（1）复杂查询理解与策略选择： 如何根据问题类型动态选择检索路径，包括单轮检索、多轮检索及混合检索策略？（2）多源信息整合与去噪： 如何有效融合本地知识库与外部检索结果，并对冗余或噪声信息进行过滤与优化？**（3）深度生成与抗干扰能力：** 如何在生成阶段引入自我反思、多步推理等机制，提升模型对噪声信息的鲁棒性？

参与本赛题，选手将深入掌握DeepSearch系统的核心技术，并在实践中探索下一代智能检索与生成系统的创新方案。

#### 赛题任务

参赛者需基于FlashRAG框架，设计并实现一个智能DeepSearch系统，针对给定的复杂问题，通过自定义的DeepSearch流程生成答案。具体任务包括但不限于：

（1）灵活检索系统设计： 根据输入问题，动态选择检索策略（如问题改写、多轮检索、混合检索等），并从本地知识库与外部检索接口中获取相关信息。
（2）多源信息融合与优化： 对检索结果进行去噪、重排序与信息融合，可尝试基于知识图谱、语义聚类等方法对多源文档进行重构与增强。
（3）深度问答生成： 设计生成模型的输入格式与生成策略，引入多步推理、自我反思等机制，提升生成答案的准确性与全面性。

特别说明：

• 系统可调用外部检索接口（如搜索引擎API）以补充信息，但需保证数据的合规性与可追溯性。
• 生成模型的单模型参数量不得超过32B，推荐使用QwQ-32B等先进推理模型。

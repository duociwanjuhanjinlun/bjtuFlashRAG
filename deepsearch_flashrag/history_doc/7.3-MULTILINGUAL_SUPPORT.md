# 中英文答案支持改进

## 问题描述

数据集中包含中英文混合的问题和答案：
- 英文问题：如 "What is the full name of the coach?"
- 中文问题：如 "某日本音乐家，26岁开始加入日本知名乐团，该乐团的名称中包含日本知名城市，请问该音乐家是谁？"
- 英文答案：如 "Kai Tomety", "Cinematography, 2012"
- 中文答案：如 "椎名林檎", "费翔", "青年拔尖人才", "阿莫西林"

## 已实施的改进

### 1. 答案提取器改进 (`utils/improved_answer_extractor.py`)

#### 改进前的问题：
- 只支持英文的 "So the answer is:" 格式
- 只匹配英文人名（大写字母开头）
- 不识别中文字符

#### 改进后的功能：
- ✅ 支持英文格式：`"So the answer is: [answer]"`
- ✅ 支持中文格式：`"答案是：[答案]"`, `"答案：[答案]"`, `"最终答案是：[答案]"`
- ✅ 支持中英文混合格式
- ✅ 识别中文实体（2-10个中文字符）
- ✅ 识别英文人名（大写字母开头的短语）
- ✅ 优先提取中文实体（通常在答案位置）

#### 关键代码改进：

```python
# 支持中英文答案标记
patterns = [
    # 英文格式
    r"So the answer is:\s*(.+?)(?:\.|$|\n)",
    # 中文格式
    r"答案是[：:]\s*(.+?)(?:[。\.]|$|\n)",
    r"答案[：:]\s*(.+?)(?:[。\.]|$|\n)",
    # ...
]

# 识别中文实体
chinese_pattern = r'([\u4e00-\u9fff]{2,10}(?:[，,、][\u4e00-\u9fff]{2,10})*)'
```

### 2. Prompt模板改进 (`prompts/ircot_concise_prompt.py`)

#### 改进内容：
- ✅ 添加中文答案格式说明
- ✅ 提供中英文示例
- ✅ 明确要求根据问题语言选择答案格式

#### 关键改进：

```python
# 支持中英文答案格式
4. When you reach the final answer, you MUST start with 
   "So the answer is:" (for English) or "答案是：" (for Chinese) 
   followed by ONLY the answer
6. The answer format should match the language of the question
```

### 3. 配置文件改进 (`configs/wq_v1_critical_fix.yaml`)

#### 改进内容：
- ✅ 更新答案模式，支持中文字符
- ✅ 使用Unicode范围匹配中文

#### 配置更新：

```yaml
# 支持中英文、数字、标点的答案模式
answer_pattern: '[\u4e00-\u9fffA-Za-z][\u4e00-\u9fffA-Za-z0-9\-_\s.,;:()，。、]+'
```

其中：
- `\u4e00-\u9fff`: 中文字符范围
- `A-Za-z`: 英文字母
- `0-9`: 数字
- `，。、`: 中文标点

## 预期效果

实施这些改进后：
1. ✅ 能够正确提取英文答案（如 "Kai Tomety"）
2. ✅ 能够正确提取中文答案（如 "椎名林檎", "费翔"）

4. ✅ 提高中文问题的准确率

## 注意事项

1. **答案格式要求**：
   - 模型必须按照prompt要求的格式输出
   - 英文问题 → "So the answer is: [answer]"
   - 中文问题 → "答案是：[答案]"

2. **答案提取优先级**：
   - 优先提取 "So the answer is:" 或 "答案是：" 后的内容
   - 如果没有找到格式标记，尝试提取中文实体或英文人名
   - 最后才使用通用提取策略

3. **答案长度限制**：
   - 如果答案超过100个字符，只取第一句或前100个字符
   - 支持中文字符计数（一个中文字符 = 1个字符）
